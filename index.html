QUICK START / 04 STEPS

从安装到运行

01

关闭 Maya

保存当前场景并退出 Maya，避免安装时旧模块仍被占用。

02

运行安装包

双击 Bingo ToolBox EXE，按提示完成安装；无需手动指定 scripts 路径。

03

重新打开 Maya

启动 Maya 后等待模块加载，在顶部菜单栏找到 Bingo 入口。

04

选择并运行工具

进入 Bingo → ToolBox，按分类浏览工具；正式处理前建议保存场景副本。

Maya 菜单栏 → Bingo → ToolBox → 选择分类 → 打开工具
