Bingo ToolBox 使用手册

  1. 安装工具箱

    运行 EXE 安装程序并选择工具箱目录。安装器会自动创建 Maya module 入口。

    默认路径 D:\Maya_Tool\Bingo_Tools
  2. 重新启动 Maya

    安装完成后重新启动 Maya，从顶部 Bingo 菜单进入 ToolBox。

    Maya → Bingo → ToolBox
  3. 查找与运行工具

    按动画、绑定、模型或特效分类筛选，选择工具后查看功能、步骤和注意事项。

  4. 添加自定义脚本

    在工具箱内新建工具，填写名称、说明、图标和 Python / MEL 执行命令。
