丢失贴图查找器

扫描当前 Maya 场景中已经丢失的贴图路径，在指定目录及其子目录中自动查找对应文件，并将找到的贴图重新链接到原贴图节点。

功能介绍

  • 一键修复：点击一次即可扫描场景、搜索贴图、判断所属模型、解决安全的同名冲突并重新链接。
  • 常见渲染器节点：支持 Maya File、Arnold、Redshift 等常见贴图节点和路径属性。
  • 复杂贴图类型：支持普通图片、UDIM 贴图组、图片序列、中文文件名及部分旧场景乱码路径。
  • 按模型智能匹配：结合模型命名空间、Reference 资产、模型根组、原路径相似度和整套贴图覆盖率选择匹配目录。
  • 同名贴图保护：多个角色或模型存在同名贴图时，优先在各自资产目录中匹配，减少串贴图。
  • 中文路径安全处理：必要时将贴图复制到当前工程的 sourceimages/Bingo_Recovered_Textures 后再链接。
  • 自动刷新视口：修复后自动开启并刷新 Maya 视口贴图显示。
  • 可恢复操作：每次修复都会保存旧路径，可使用 Maya 撤销或“更多 → 恢复上次路径”。
  • 未解决项管理：可查看没有找到、存在冲突、路径为空或属性不可写的节点，并为指定模型锁定贴图目录。

使用方法

  1. 打开需要修复贴图的 Maya 场景。工具会扫描整个场景，不需要事先选择模型。
  2. 打开“丢失贴图查找器”。
  3. 在“搜索目录”中点击添加目录…，加入存放贴图的文件夹；可以添加多个目录。
  4. 如果贴图位于当前 Maya 工程中，可点击添加工程 sourceimages。
  5. 点击一键修复全部贴图。工具会自动递归扫描子目录，并只处理当前丢失的贴图节点。
  6. 查看下方结果摘要，确认成功修复数量、自动解决冲突数量及未解决数量。
  7. 检查视口贴图效果；确认正确后手动保存 Maya 场景。

搜索目录说明

  • 添加目录…：增加一个贴图库或资产目录，工具会递归搜索其所有子目录。
  • 添加工程 sourceimages：快速加入当前 Maya 工程的标准贴图目录。
  • 移除所选：从搜索范围中移除当前选中的目录，不会删除硬盘文件。
  • 清空：清空本工具的搜索目录列表，不会删除贴图文件。
  • 搜索目录会被记住，下次打开工具时无需重复添加。

未解决项处理

  1. 点击更多 → 查看未解决项…，查看未找到、冲突、空路径或锁定属性。
  2. 如果多个角色存在同名贴图，选择相关模型后使用更多 → 为模型指定贴图目录…。
  3. 指定正确的资产贴图目录后，再次点击一键修复全部贴图。
  4. 引用文件或锁定节点无法写入时，需要先解除锁定，或在资产源文件中修复。

恢复上次路径

  1. 点击更多 → 恢复上次路径。
  2. 确认后，工具会将上一轮处理过的节点恢复到操作前的贴图路径。
  3. 恢复路径不会删除已经复制到工程目录中的贴图文件。

注意事项

  • 工具不会自动保存 Maya 场景。确认贴图正确后，请手动保存文件。
  • 贴图库中存在大量同名文件时，请检查匹配结果；必要时为模型指定独立贴图目录。
  • 搜索目录必须真实存在且当前用户具有读取权限。
  • 引用资产的锁定属性可能无法直接修改，需要在引用源文件中处理。
  • “恢复上次路径”只恢复节点路径，不会删除工具复制出的贴图文件。
  • 兼容 Maya 2020、2021、2022、2023、2024、2025 和 2026。

推荐流程：添加贴图根目录 → 一键修复 → 检查未解决项 → 验证视口 → 手动保存场景。
