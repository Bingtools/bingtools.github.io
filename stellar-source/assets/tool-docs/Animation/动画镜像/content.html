姿态 / 动画镜像

工具具体功能

  • 按照左右命名规则镜像当前姿态或整段关键帧动画。
  • 支持自定义左右标记和中心控制器自身镜像。
  • 可指定平移、旋转和缩放通道的取反轴。
  • 提供 IK、FK 预设与逐整数帧烘焙。

工具使用教程

  1. 选择左到右、右到左或左右交换模式。
  2. 确认左右命名规则与角色控制器名称一致。
  3. 选择需要镜像的控制器，并设置需要取反的通道。
  4. 单帧操作点击镜像姿态。
  5. 动画操作设置帧范围和是否逐帧烘焙，再点击镜像动画。
  6. 检查脚部、手部和中心控制器的结果。

注意事项

  • 不同绑定的镜像轴可能不同，应先在单帧副本上测试。
  • 约束或驱动控制器建议启用逐整数帧烘焙。
