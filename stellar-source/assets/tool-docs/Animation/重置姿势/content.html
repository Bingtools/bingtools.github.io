重置姿势

作者：Bingo　版本：1.1.0（Animo 兼容识别修正版）

将所选控制器恢复到正确归位姿势。优先读取 Animo 已保存的自定义归位数值，找不到时使用 Maya 属性本身的默认值。

  • 通道盒选中属性时，只处理选中的属性。
  • 曲线编辑器选中关键帧时，只修改选中的关键帧。
  • 时间滑块框选范围时，只修改范围内已有关键帧。
  • 普通选择时，重置当前帧；已有动画会写入真实关键帧。
  • 兼容 Animo channelbox_attributes.json 保存的归位值，并支持引用命名空间。
  • 普通直连 AnimCurve 可正常处理；pairBlend/动画层/blendWeighted 等多输出网络在曲线和范围模式下会明确跳过，避免误改相邻通道。
  • Set Driven Key（UA/UL/UT/UU）会被识别为非时间驱动并安全跳过，不改 SDK 映射或断开 Driver 连接。
  • 当前帧对动画层写入关键帧后会立即刷新 DG，避免出现“数值已写入但视口没变”。
  • 锁定、非数值和非动画连接驱动的属性会被安全跳过。
  • 操作结果会显示成功、跳过、失败数量及首条原因，不再静默失败。
  • 整次操作支持 Maya Ctrl+Z 撤销。

快捷栏中的“重置姿势”图标可直接执行，无需打开额外窗口。
