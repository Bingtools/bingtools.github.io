IKFK 无缝切换

工具具体功能

  • 在 IK 与 FK 状态之间匹配角色姿态，减少切换时的跳变。
  • 支持识别角色命名空间并匹配对应控制器。
  • 可结合当前帧或动画范围完成切换和关键帧写入。

工具使用教程

  1. 选择角色的 IK、FK 或相关肢体控制器。
  2. 打开工具并确认识别到正确的角色命名空间。
  3. 选择需要切换的肢体和目标模式。
  4. 在目标帧执行 IK 转 FK 或 FK 转 IK。
  5. 播放切换前后帧，检查关节位置和旋转是否连续。

注意事项

  • 角色必须符合工具支持的控制器命名和层级规则。
  • 切换前建议在前后帧保留稳定关键帧，避免插值产生滑动。
