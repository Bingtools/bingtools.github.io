空间属性切换

在保持动画世界姿态的前提下，切换控制器旋转顺序或绑定空间属性。

旋转顺序

  • 支持 XYZ、YZX、ZXY、XZY、YXZ、ZYX 六种顺序。
  • 有旋转动画时，在原关键帧重新匹配世界朝向。
  • “分析动画并设为最佳”会检查全部旋转关键帧，并降低最大万向节风险。

空间属性

  • 选择一个或多个控制器后，自动列出共同的 Space、Parent、Follow、IK/FK 等属性。
  • “仅当前帧”适合在当前时刻切换空间。
  • 取消勾选后会逐帧烘焙整段动画，结果更稳定，但关键帧会增加。
  • 切换过程中保留世界位置、旋转和缩放，不删除绑定原有用户属性。

使用方法

  1. 选择需要处理的动画控制器。
  2. 直接点击旋转顺序，或选择空间属性和目标值。
  3. 确认“仅当前帧”状态后点击“应用空间属性切换”。

提示：整次操作支持 Ctrl+Z。rotateOrder 已锁定、被连接或自身带动画的对象会被安全跳过。
