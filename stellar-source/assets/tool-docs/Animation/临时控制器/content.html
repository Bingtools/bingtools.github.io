临时控制器

作者：Bingo　版本：1.0.0　兼容 Maya 2020–2026

在指定动画范围内创建可烘焙的临时控制器，用于整体调整、空间切换、动画修形和枢轴编辑。

工具具体功能

  • 为所选对象逐个创建临时控制器，或为两个以上对象创建一个整体控制器。
  • 支持时间滑块选区与播放范围，并提供圆形、方形、立方体形状和尺寸设置。
  • 可抓取到参考对象、释放到世界，以及只切换位移空间或旋转空间，切换时保持世界姿势。
  • 可添加父控制器、子控制器，修改控制层级，并重新应用形状与大小。
  • 可把枢轴移到参考对象、居中、留在世界位置或恢复默认枢轴。
  • 完成后可把结果烘焙回原对象并清理临时系统，也可不烘焙直接删除。

明确使用步骤

  1. 先在时间轴框选需要处理的范围；如果没有框选，选择 播放范围。设置控制器形状与大小。
  2. 选择一个或多个需要调整的控制器或对象。点击 逐个创建；需要统一控制两个以上对象时，点击 整体控制器。
  3. 在新建的临时控制器上制作或修改动画。
  4. 需要跟随其他物体时，先选择临时控制器，再按住 Shift 最后选择参考对象，然后点击 抓取到所选、仅位移空间 或 仅旋转空间。回到世界空间时只选临时控制器并点击 释放到世界。
  5. 需要更多控制层时使用 添加父控制器 或 添加子控制器；需要改变旋转中心时使用枢轴区域的相应按钮。
  6. 确认动画后点击 烘焙并清理，把当前范围的结果写回原对象并移除临时系统。
  7. 如果不需要临时控制器上的修改，点击 直接删除，仅移除临时系统。

主要按钮说明

  • 抓取到所选：临时控制器完整跟随最后选择的参考对象。
  • 仅位移 / 仅旋转空间：只改变对应空间，另一部分保持独立。
  • 枢轴到所选：把主要临时控制器枢轴移到最后选择的参考对象。
  • 应用形状与大小：把当前形状和尺寸设置应用到选中的临时控制器。

注意事项

  • 整体控制器至少需要选择两个对象。
  • 空间切换和“枢轴到所选”要求参考对象最后选择。
  • “直接删除”不会把临时控制器上的动画烘焙回原对象。
  • 时间滑块没有有效选区时，工具会自动使用播放范围。
  • “烘焙并清理”会保留动画层，只清理当前 Bingo 临时系统；整次操作支持 Ctrl+Z。
