Maya 文件批量处理

工具具体功能

  • 批量扫描文件夹中的 Maya ASCII 和 Maya Binary 场景。
  • 导入 TXT 文本，并对每个场景执行文本中的 Python 代码。
  • 支持包含子目录、覆盖前备份以及自动另存输出。
  • 提供文件列表和批处理进度控制。

工具使用教程

  1. 选择包含 Maya 文件的源文件夹。
  2. 选择 .ma、.mb 以及是否包含子文件夹。
  3. 选择“另存到自动输出目录”或“覆盖原文件”。
  4. 点击“导入 TXT”，选择包含批处理 Python 代码的文本文件。
  5. 确认文件列表后点击开始批量处理。
  6. 另存模式的结果会自动保存到源文件夹内的 Bingo_Batch_Output 文件夹。

注意事项

  • 正式批处理前先用少量副本测试自定义代码。
  • 覆盖原文件前建议开启备份；另存模式不会修改源文件。
  • 处理期间不要关闭 mayabatch 或强制结束工具。
