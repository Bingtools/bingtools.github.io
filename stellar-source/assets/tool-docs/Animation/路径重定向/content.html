路径重定向

把角色原有运动重新映射到可编辑曲线。工具保留稳定烘焙模式，并新增经授权整合的完整高级模式。

工具具体功能

  • 从角色主控制器动画生成可编辑的运动路径。
  • 按原动画行进距离将根运动映射到目标曲线。
  • 可让角色朝向跟随路径，并保留原动画上下起伏。
  • 自动识别脚部接触段，减少落地脚滑动。
  • 应用前自动保留场景内备份，可一键恢复。
  • 完整高级版支持任意多控制器连接到可编辑曲线结构。
  • 支持快速/精确路径、CV 与曲线控制器、拉直、反向、贴地、变形和前后滑动。
  • 支持主控跟随、世界控制器重新定位、定位器外观以及完整烘焙清理。

使用方法

  1. 选择角色总控或根控制器，点击“读取选择”。
  2. 选择左脚、右脚等落地控制器，点击“读取多选”。
  3. 点击“从主控制器动画生成路径”，然后编辑生成的曲线；也可以直接指定现有 NURBS 曲线。
  4. 设置时间范围和脚锁灵敏度，点击“应用重定向并烘焙”。
  5. 需要回到应用前状态时，点击“恢复上一次应用前动画”。
  6. 需要完整生产功能时，点击“打开完整高级版（全部功能）”。先创建或指定路径，再指定任意控制器并“连接到曲线”；编辑完成后使用“烘焙并删除”。

注意事项

  • 主控制器必须在时间范围内具有水平位移动画。
  • 脚部控制器的位移或旋转通道若被锁定，将只烘焙可用通道。
  • 第一次在新绑定上使用时，建议先保存场景副本并检查脚锁灵敏度。
  • 稳定模式负责真正的脚部接触检测；完整高级模式对用户指定控制器做通用世界空间补偿，不会自动识别左右脚。
  • 完整高级模式逐帧计算且会创建临时结构，长镜头、多控制器或复杂引用绑定请先在场景副本中验证。
