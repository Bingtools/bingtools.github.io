Studio Library

工具具体功能

  • 保存和管理角色姿态、动画片段及选择集。
  • 通过缩略图浏览资产，并在不同 Maya 场景之间复用。
  • 支持按文件夹组织个人库或项目共享库。

工具使用教程

  1. 打开 Studio Library 并选择或创建库目录。
  2. 在 Maya 中选择角色控制器。
  3. 使用保存功能创建姿态或动画条目，并填写名称和缩略图。
  4. 需要复用时选择目标角色，再双击或应用库中的条目。
  5. 检查命名空间和控制器映射结果。

注意事项

  • 共享库目录应放在所有用户都能访问的稳定路径。
  • 保存动画前确认时间范围，应用到其他角色时确认绑定结构兼容。
