动画路径

工具具体功能

  • 为选中控制器创建实时运动轨迹。
  • 可设置时间范围、轨迹粗细、颜色和前后帧数量。
  • 支持世界空间或相机空间显示，并可创建可移动 Offset 跟踪点。

工具使用教程

  1. 选择需要观察运动路径的控制器。
  2. 设置开始结束帧或使用时间滑块范围。
  3. 调整轨迹颜色、粗细、间隔和显示模式。
  4. 选择世界或相机空间。
  5. 点击创建运动轨迹。
  6. 需要调整观察位置时创建 Offset 跟踪点，完成后可删除轨迹。

注意事项

  • 长时间范围和大量控制器会增加视口计算量。
  • 角色绑定较重时建议减少轨迹数量和前后帧显示数量。
