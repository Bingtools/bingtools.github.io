路径指认

工具具体功能

  • 选择一个项目文件夹后，自动识别该目录及全部子文件夹中的文件。
  • 支持按 Maya、FBX、OBJ、Alembic、脚本等类型筛选，也可按文件名或子路径搜索。
  • 列表使用相对路径显示，同名文件位于不同子目录时也能准确区分。
  • 支持打开选中、导入选中、选中新建导入，以及引用选中的 Maya 文件。
  • 常用项目目录可加入收藏夹，双击收藏即可重新扫描该目录。

工具使用教程

  1. 点击“浏览”并选择具体的项目文件夹；工具会自动扫描全部子文件夹，无需额外勾选。
  2. 在“类型”中选择需要的文件格式，或输入文件名、子路径进行筛选。
  3. 在文件列表中选择一个或多个文件。
  4. 根据需要点击“打开选中”“导入选中”“选中文件引用”或“选中新建导入”。
  5. 项目内容变化后，点击“刷新（含子文件夹）”重新扫描。

注意事项

  • 为避免 Maya 长时间无响应，请选择具体项目文件夹，不要直接扫描磁盘根目录或网络共享根目录。
  • 扫描大量文件时会显示进度窗口，可随时点击取消；已读取的文件仍会保留在列表中。
  • 工具不会跟随符号链接或 Windows Junction，且不能把这类链接本身作为扫描根目录，避免目录循环和重复文件。
  • “选中文件引用”沿用原有规则，仅支持 .ma 和 .mb；其他格式请使用导入。
  • 打开工具时仅快速读取初始目录当前层；选择路径、收藏夹或点击刷新后默认递归扫描。
