改帧颜色

工具具体功能

  • 为时间轴关键帧或帧范围添加颜色标记。
  • 支持更新颜色、跳转到标记、显示或隐藏标记。
  • 可调整全局关键帧显示宽度并恢复默认状态。
  • 支持恢复当前帧或场景中所有特殊颜色关键帧为普通颜色。

工具使用教程

  1. 在时间轴选择需要标记的帧或范围。
  2. 选择标记颜色并点击标记时间轴选区。
  3. 在颜色标记列表中选择记录，可更新颜色或跳转。
  4. 使用显示全部、隐藏全部管理标记可见性。
  5. 需要清除单帧特殊颜色时，使用“当前帧恢复普通颜色”或“恢复所有单帧颜色到普通颜色”。
  6. 不再需要时删除选中标记或清空本工具标记。

注意事项

  • 清空本工具标记只应删除本工具创建的数据。
  • 修改全局帧宽会影响当前 Maya 时间轴显示。
