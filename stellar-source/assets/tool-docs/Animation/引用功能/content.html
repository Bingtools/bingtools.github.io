引用功能

选中内容转引用

  1. 在当前 Maya 场景中选择一个或多个本地模型的最外层组。
  2. 选择引用源文件保存路径，或使用自动路径。
  3. 点击“将当前选择转换为引用”。
  4. 工具会先导出 Maya 文件，确认引用创建成功并保持位置后，再删除本地节点。

引用本地文件

  • 支持 .fbx、.ma、.mb 三种引用文件，扩展名大小写均可识别。
  • 点击“添加文件夹（含子文件夹）”后，默认递归识别所选文件夹及全部子文件夹，不需要勾选任何额外选项。
  • 同一文件不会重复加入列表；再次扫描父目录、子目录或手动添加时会自动跳过重复项。
  • 如果扫描目录包含当前正在打开的 Maya 场景，工具会自动跳过，避免场景引用自身。
  • 每个文件自动使用独立命名空间，并在名称冲突时自动编号。
  • 支持创建为延迟加载引用。
  • 引用 FBX 时会自动检查并加载 Maya 自带的 fbxmaya 插件；插件不可用时只跳过对应 FBX，并继续处理其他文件。

引用管理

  • 查看当前场景引用节点、命名空间、加载状态和源文件路径。
  • 支持重新加载、卸载、替换引用文件和移除引用。
  • “替换引用文件”沿用原有 Maya 文件流程，目前仅选择 .ma 或 .mb；FBX 可重新添加为新引用。
  • 移除引用只影响当前场景，不会删除磁盘上的源文件。

注意事项

  • 同时选择父层和子层时，工具只转换最外层根节点，避免重复导出。
  • 已经被引用的节点不会再次转换。
  • 如果模型与选择范围外的约束、表达式或节点存在连接，请先检查外部依赖。
  • 部分 Maya 版本无法稳定读写包含中文或特殊字符的文件路径；遇到路径错误时请改用纯英文路径。
