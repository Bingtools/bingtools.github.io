Animation Helper

工具具体功能

  • 集中提供常用动画辅助操作，减少在 Maya 菜单和编辑器之间切换。
  • 面向控制器选择、关键帧处理和动画检查等高频流程。
  • 作为独立窗口运行，可与时间轴和曲线编辑器配合使用。

工具使用教程

  1. 打开工具后，先在 Maya 中选择需要处理的控制器或动画对象。
  2. 根据当前任务选择对应的动画辅助功能。
  3. 设置帧范围、轴向或处理选项。
  4. 执行操作并在时间轴或曲线编辑器中检查结果。
  5. 结果不符合预期时立即撤销并调整选项后重试。

注意事项

  • 执行批量关键帧操作前建议保存场景。
  • 不同按钮对选择对象和关键帧范围的要求可能不同，请先确认当前选择。
