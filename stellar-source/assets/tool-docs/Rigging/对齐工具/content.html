对齐工具

工具功能

  • 将一个或多个对象的位置、旋转、缩放批量匹配到同一个目标。
  • 位置、旋转、缩放可分别启用，并支持单独选择 X、Y、Z 轴。
  • 使用世界空间匹配位置与旋转，适用于不同父级下的对象。
  • 执行过程合并为一次 Maya 撤销操作。

使用步骤

  1. 先选择需要被对齐的一个或多个对象。
  2. 最后选择目标对象；最后选中的对象始终作为目标。
  3. 设置需要对齐的变换类型和轴向。
  4. 点击“执行对齐”。如需恢复，可按 Ctrl+Z。

窗口操作

  • 按住标题栏或窗口空白区域可以拖动窗口，移动逻辑与 IKFK 工具一致。
  • 拖动窗口四边或四角可以调整窗口大小。
  • 点击右上角加宽的关闭按钮可关闭工具。

注意事项

  • 至少需要选择两个对象。
  • 锁定、约束或被连接的变换通道可能无法被修改。
  • 缩放按对象的 scale 通道进行匹配。
