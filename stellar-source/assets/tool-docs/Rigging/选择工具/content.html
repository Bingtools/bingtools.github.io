选择工具

工具功能

  • 根据节点类型快速选择或反选场景对象。
  • 支持层级、当前选择和全部节点三种处理范围。
  • 可以一次读取多个节点类型。
  • 开启 Transform 与 Shape 合并计算后，Shape 会返回对应的 Transform 对象。

使用步骤

  1. 选择一个或多个示例对象。
  2. 点击“载入节点”，工具会读取 mesh、nurbsCurve、joint 等节点类型。
  3. 选择“层级”“当前选择”或“全部节点”。
  4. 点击“选择”筛选匹配节点，或点击“反选”筛选其余节点。

范围说明

  • 层级：从当前选择及其子层级中筛选。
  • 当前选择：只在当前选中的对象中筛选。
  • 全部节点：在整个 Maya 场景中筛选。

注意事项

  • “全部节点 + 反选”可能选中大量节点，复杂场景中建议谨慎使用。
  • 输入多个类型时使用英文逗号分隔，例如 mesh, nurbsCurve。
