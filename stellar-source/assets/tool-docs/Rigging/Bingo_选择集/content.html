Bingo_选择集

自研的 Maya 可视化选择器，可把控制器、模型和组件保存为画布按钮。

主要功能

  • 从当前 Maya 选择创建一个或多个对象的选择集按钮。
  • 解锁后在画布空白处按住中键拖动，可为当前选择的多个对象分别创建独立按钮；拖动方向决定排列方向。
  • “编辑 > 从当前选择创建”继续作为组合模式，可把多个对象保存到同一个按钮；顶部重复按钮已移除。
  • 编辑模式下可拖动按钮，并调整标签、尺寸、字号、按钮颜色和文字颜色；也可直接拖动按钮边缘或四角改变大小。
  • 按钮支持圆角矩形、矩形、胶囊、椭圆、菱形和六边形六种外观。
  • 底部直接显示六个形状按钮，不再使用下拉框；多选布局按钮后点击任一形状，或使用已选按钮的右键形状菜单，可同步修改全部已选按钮。
  • “形状与尺寸”层直接排列六种形状、宽、高和“应用按钮大小”；填写宽高后点击应用，单选修改当前按钮，多选同步修改全部已选按钮，未选按钮时设置新建按钮的默认大小。
  • 双击按钮、右键菜单或回车均可重命名按钮。
  • 右键菜单删除按钮时直接执行；右键按钮属于多选范围时会一次删除全部已选按钮。解锁后按 Delete 也可直接删除单个或多个已选布局按钮；菜单栏删除仍保留确认提示。
  • 拖动窗口四边或四角可缩放；双击标题栏可最大化或还原。
  • 普通点击替换选择；Shift 追加；Ctrl 切换；Alt 从当前选择中移除。
  • 支持命名空间自动解析，角色引用命名空间改变后仍可尝试匹配控制器。
  • “命名空间”、刷新按钮和“只显示画布”集中放在顶部“解锁编辑”之后；对齐图标栏只保留布局工具。
  • 选择器数据自动保存在当前场景，也可导出或导入 JSON 文件。
  • 同一窗口可以同时打开多个选择集文件，每个文件显示为一个独立标签页。
  • 每个标签页可独立设置画布宽高、背景图片、透明度和图片显示方式，不会影响其他标签页。
  • 画布大小既可输入数值，也可通过“框选设置画布大小”拖出矩形；右键会显示“确认设置 / 取消”，只有确认后才应用。
  • “恢复默认画布大小（900 × 620）”只恢复当前标签页尺寸，按钮、画布颜色、背景图片和透明度保持不变。
  • 双击或右键标签页可重命名选择集；名称会随选择集文件保存。
  • 新建“＋”按钮紧跟在最后一个选择集标签后方。
  • 首次保存时自行选择目录；之后可直接保存、另存为或保存全部。
  • 布局默认锁定，避免误拖动或误改按钮；解锁后才开放编辑功能。
  • 属性区只保留外观与布局功能；改名使用双击或右键，更新成员和删除使用右键菜单。
  • 底部属性区整理为“外观 / 形状与尺寸 / 排列”三层，统一行高、边距和分组色条。
  • “外观”集中画布颜色、按钮颜色、文字颜色、字号、间距和画布设置；“形状与尺寸”集中形状和精确宽高；“排列”集中全选、智能排列、统一尺寸、基准、排列选项与关闭窗口。
  • 解锁后按住 Shift 点击可持续加选按钮，重复点击已选按钮不会取消。对齐基准可选择“选择范围”“主按钮”或“画布”。
  • 在画布空白处拖动可框选范围内按钮；按住 Shift 再框选可追加到已有多选。
  • 支持 DWPicker 风格的中心等距、可见边缘等距、指定像素间距和间距 0 的紧密排列。
  • 可将所选按钮整体置于画布水平、垂直或完全中央，也可水平或垂直反转所选按钮位置。
  • 智能排列可识别横排、竖排和多行多列网格，也可在排列前自动统一最大宽高。
  • 标签页下方提供 17 个直观小图标，直接执行基础对齐、中心/边缘等距、指定间距、紧密排列、整体置中、反转和镜像创建。
  • 统一宽度、高度、宽高图标保留在属性区；右键统一宽高图标可选最大、最小和平均尺寸。
  • 支持单个或批量左右、上下对称镜像创建；自动尝试互换 L/R、Left/Right、左/右名称和成员。
  • 多选后拖动其中一个按钮，可整体移动全部已选按钮。
  • 多选后拖动任一已选按钮的边缘或四角，可同步调整全部已选按钮尺寸。
  • 双击画布空白处可进入或退出“只显示画布”；该模式保留标签切换并隐藏其他编辑界面，拖动画布空白处可移动窗口，按 Esc 或右键可恢复。

使用方法

  1. 在 Maya 中选择需要记录的控制器、模型或组件。
  2. 点击“解锁编辑”，再使用“编辑 > 从当前选择创建”。
  3. 需要批量独立按钮时，选中多个 Maya 对象后，直接在画布空白处按住中键拖动。
  4. 完成排版后点击“锁定布局”，此时只能使用按钮进行选择。
  5. 通过标签后的“＋”新建标签页；双击或右键标签可重命名。
  6. 通过“文件”菜单打开或保存选择集；其中还提供“另存为”和“保存全部”。
  7. 点击底部六个形状按钮切换按钮外观；多选时会同步修改所有已选按钮，双击按钮可快速改名。
  8. 通过“画布设置”可修改当前标签页画布尺寸、背景图片、显示方式与透明度。
  9. 选择“框选设置画布大小”后，在画布上拖出矩形；松开可检查范围，右键选择“确认设置”才应用，选择“取消”则退出本次框选，左键可重新框选。
  10. 批量整理时，按 Shift 点击或框选多个按钮，再使用顶部对齐工具栏、智能排列或底部统一尺寸图标。
  11. “基准”默认使用所选按钮整体范围；切换为“主按钮”时以最后点击的蓝色按钮为准，切换为“画布”时按画布边缘或中心对齐。
  12. 在“间距”中输入像素值后，可应用水平或垂直指定间距；多选后拖动任一已选按钮可整体移动。
  13. 顶部工具栏末尾三个带菜单图标分别提供整体置于画布、反转所选按钮位置和对称镜像创建。
  14. 误操作后按 Ctrl+Z，可恢复最近一次批量布局、成组拖动或尺寸调整；即使焦点停留在刚点击的功能按钮上也能触发，切换标签页会清除该撤销记录。
  15. Ctrl+Z 与 Delete 只在 Bingo_选择集窗口处于当前操作窗口时生效；切换到 Maya 或其他窗口后不会处理这些按键。
  16. 底部原“撤销”按钮已改为“关闭窗口”；点击后直接关闭 Bingo_选择集。
  17. 完成布局后可点击“只显示画布”进入纯使用模式；可切换标签并拖动画布空白处移动窗口，按 Esc 或右键恢复完整界面。
  18. 需要替换成员时，先在 Maya 重新选择，再点击“更新成员”。
  19. 场景保存后选择集会一起保存；跨场景复用时使用 JSON 导入/导出。

注意事项

  • 同名控制器存在于多个命名空间时，请在窗口右上角指定命名空间。
  • 删除角色或修改控制器名称后，无法匹配的成员会在状态栏提示。
  • 场景数据保存在名为 Bingo_SelectionSet_DATA 的 network 节点中。
