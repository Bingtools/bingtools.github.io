AdvancedSkeleton

工具具体功能

  • 启动 AdvancedSkeleton 角色绑定系统。
  • 提供骨架定位、自动绑定、面部系统和变形辅助流程。
  • 适合标准双足、多足及自定义角色的快速绑定。

工具使用教程

  1. 准备干净模型并确认比例、朝向和冻结状态。
  2. 打开 AdvancedSkeleton，创建或载入 FitSkeleton。
  3. 调整骨骼定位点与模型结构匹配。
  4. 执行 Build AdvancedSkeleton 生成控制器和绑定结构。
  5. 测试变形、IK/FK、镜像和极限姿态。

注意事项

  • 这是完整绑定系统，正式构建前应阅读对应版本的 AdvancedSkeleton 文档。
  • 重建绑定前备份权重、角色设置和自定义修改。
