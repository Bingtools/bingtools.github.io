约束工具

主要功能

  • 快速创建父子、点、方向、缩放、瞄准和极向量约束。
  • 位置、旋转或位置+旋转快速对齐，不保留约束节点。
  • 管理约束目标、权重、静音、删除及烘焙。
  • 创建动画空间切换，支持抓取、释放和保持姿势切换。
  • 创建临时控制器，在不丢失原动画的情况下进行二次调整。
  • 处理已有绑定的 Space / Parent / Follow 空间属性。

快速使用

  1. 先选择约束目标。
  2. 最后选择需要被约束的对象。
  3. 在“跟随”页面选择需要的约束类型。
  4. 如需编辑权重、烘焙或更完整的设置，进入“高级”页面。

窗口操作

  • 按住顶部标题栏可拖动窗口。
  • 拖动窗口边缘或右下角可调整大小。
  • 进入高级页面后，窗口会根据子页面内容自动调整。

工具会直接修改 Maya 场景，重要操作前建议保存文件。
