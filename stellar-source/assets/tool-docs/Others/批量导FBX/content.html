Bingo_批量导FBX

工具功能

  • 扫描当前场景中的根骨骼，并将选择的骨骼批量导出为 FBX。
  • 批量扫描文件夹中的 MA、MB 文件，逐个打开、识别骨骼并导出。
  • 提供仅骨骼、骨骼与蒙皮、骨骼与动画、完整导出四种预设。
  • 输出目录自动生成：每个源文件旁创建 FBX 文件夹。

基本使用

  1. 在“当前场景”或“批量文件”页选择工作模式。
  2. 扫描并勾选需要导出的骨骼或 Maya 文件。
  3. 选择导出预设，点击“开始导出”。
  4. 工具会自动创建 FBX 文件夹并保存导出结果。

路径规则

  • 已保存场景：在场景文件所在目录创建 FBX 文件夹。
  • 未保存场景：在当前 Maya 工程目录创建 FBX 文件夹。
  • 批量文件：在每个 MA/MB 源文件所在目录分别创建 FBX 文件夹。

注意事项

  • 工具依赖 Maya 自带的 fbxmaya 插件。
  • “骨骼 + 动画（不含模型）”会按当前播放范围每帧 BAKE 骨骼，再导出 FBX。
  • 骨骼 BAKE 是临时操作；导出后会自动撤销，并恢复原选择和当前帧。
  • 批量文件模式会依次打开场景，使用前请保存当前工作。
