Maya 文件预览

工具具体功能

  • 批量扫描 Maya、FBX 等资产并生成静态或动画预览。
  • 静态资产支持图片预览和可旋转的 3D 预览。
  • 动画资产支持 GIF 预览及 GLB 骨骼动画查看。
  • 支持导入、引用、打开文件、打开所在目录和清理全部预览缓存。

工具使用教程

  1. 添加一个或多个资产目录，并选择是否包含子目录。
  2. 选择正确的 Maya mayabatch 路径、分辨率和 FPS。
  3. 刷新列表并按格式或状态筛选文件。
  4. 选择文件后点击生成或更新预览；需要交互模型时点击生成 3D 预览。
  5. 在批量缩略图或单个预览模式中查看结果。
  6. 通过右键菜单导入、引用或打开资产。

注意事项

  • mayabatch 必须能独立启动，环境变量或 Maya 安装损坏会导致生成失败。
  • 3D 预览需要对应版本 PYD、QtWebEngine 和有效 metadata。
  • 删除所有预览文件不可撤销，只会清理工具生成的缓存目录。
