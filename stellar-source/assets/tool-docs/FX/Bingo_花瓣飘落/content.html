Bingo_花瓣飘落

工具功能

  • Bingo 自研的 Maya 花瓣飘落动力学工具。
  • 支持使用一个或多个所选模型作为花瓣；自动花瓣恢复原版 MEL 的 NURBS CV 建模参数与 Ramp 材质逻辑。
  • 支持 classic particle 与 nParticle 两种粒子系统。
  • 自动创建曲面发射器、重力、扰动、风场、粒子实例化和逐粒子表达式。
  • 花瓣大小、初始朝向、旋转速度和实例模型会产生随机变化。
  • 每套效果使用独立的 Bingo 命名与效果组，支持选择控制器和删除指定效果。

使用方法

  1. 选择一个或多个花瓣模型，点击 读取选择；或者选择 自动创建花瓣。
  2. 根据项目需要选择 particle 或 nParticle。
  3. 在醒目的 花瓣密度 区域调整数量；数值越小越稀疏。
  4. 在基础参数中设置发射范围、生命周期、缩放和旋转速度。
  5. 在动力参数中设置重力、扰动、风力和风向。
  6. 点击 创建花瓣飘落。
  7. 播放时间轴检查效果。控制器可移动、旋转和缩放发射区域，并可直接调整已连接的动力属性。
  8. 点击 选择控制器 找回最近创建的效果；创建后可通过控制器的 petalDensity 属性继续调整密度。
  9. 不再使用时点击 删除所选效果。

注意事项

  • 工具不会修改作为实例来源的用户模型；自动创建的花瓣会归入对应效果组。
  • 多个来源模型会随机分配给粒子实例。
  • 高发射数量和高细分花瓣模型会增加视口、缓存和渲染开销。
  • 最终输出前请按渲染器检查实例材质、透明度与运动模糊。
  • 创建动力学效果前建议保存场景。工具支持 Maya 撤销，但复杂场景中仍建议保留文件版本。
