Bingo_物理解算

工具具体功能

  • 为连续控制器生成延迟跟随和拖拽效果。
  • 支持平移烘焙、第一节保持、只向下收集子级控制器和循环动画。
  • 可叠加风力幅度与速度，制作飘带、尾巴、触须等次级运动。
  • 支持当前时间轴或自定义帧范围。

工具使用教程

  1. 按运动链顺序选择控制器，或只选一个曲线根控制器并启用“只向下收集子级”。
  2. 设置每节延迟、跟随幅度和可选风力参数。
  3. 根据绑定类型决定是否同时烘焙平移。
  4. 设置当前时间轴或自定义帧范围。
  5. 点击开始烘焙跟随效果。
  6. 播放结果并检查首尾循环、穿插和控制器旋转。

注意事项

  • 先在场景副本或动画层流程中测试，烘焙会写入大量关键帧。
  • 控制器选择顺序会影响延迟传播方向。
  • 自动收集不会搜索父级、祖先或同级节点；遇到多个子控制器分支时会停止，请手动选择要处理的单条链。
  • 复杂绑定建议关闭并行计算干扰后再核对结果。
