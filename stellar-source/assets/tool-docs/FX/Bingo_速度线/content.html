Bingo_速度线

作者：Bingo　版本：1.1.7

在一个或多个多边形武器、载具或道具表面生成可调节、可流动的卡通速度线。

工具具体功能

  • 从模型表面、尾部区域和边界采样，生成渐细的带状多边形速度线。
  • 支持根据物体运动方向、模型最长轴或局部 X/Y/Z 轴确定拖尾方向，并可反转。
  • 可设置线条数量、方向随机、随机种子、长度、粗细、粗糙度、表面偏移、颜色和透明度。
  • 支持流动动画、流动速度、流动幅度、闪烁，以及播放时实时更新运动方向。
  • 同一模型再次创建会更新原有 Bingo 速度线；可选择现有效果或完整删除。

明确使用步骤

  1. 在 Maya 中选择一个或多个包含 Mesh 的多边形武器、载具或道具。
  2. 打开工具并点击 读取选择，确认“速度线来源”显示正确模型。
  3. 设置线条数量与方向。选择“根据物体运动方向”时，速度线会沿物体实际移动方向的反方向拖尾；静止时会回退到模型最长轴。
  4. 调整方向随机、随机种子、最短/最长长度、粗细、粗糙度、表面偏移、颜色和不透明度。
  5. 需要动态效果时勾选 启用流动动画，设置流动速度、幅度和闪烁；需要播放中转向时保留“播放时实时更新运动方向”。
  6. 点击 创建 / 更新速度线，播放时间轴检查效果。
  7. 使用 选择现有效果 定位生成组；不再需要时选择源模型或效果组，再点击 删除速度线。

主要参数说明

  • 线条数量：控制生成网格数量，数量越高实时更新开销越大。
  • 随机种子：相同参数与种子会获得稳定的分布；点击“随机”可快速换一种排列。
  • 表面偏移：让速度线离开模型表面，减少穿插和闪烁。
  • 流动动画：由时间变化回调驱动速度线移动与闪烁，不会自动烘焙为逐帧顶点动画。

注意事项

  • 只接受包含 Mesh Shape 的多边形物体。
  • 最短长度大于最长长度时，工具会自动交换两个数值。
  • 线条越多，同时开启实时方向和流动动画时，播放开销越高。
  • 重新打开场景后，建议重新打开一次本工具再播放，以恢复实时更新回调。
  • 点击“删除速度线”时如果完全没有选择，工具会删除场景内全部带 Bingo 标记的速度线效果。
