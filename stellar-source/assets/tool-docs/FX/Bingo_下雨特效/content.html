Bingo_下雨特效

工具具体功能

  • 自动创建基于 Maya nParticle 的可播放雨滴系统。
  • 提供小雨、中雨、暴雨和斜风暴雨四套预设。
  • 可设置降雨区域宽度、深度、雨云高度和地面高度。
  • 支持雨量、下落速度、水平风向、扰动、雨滴长度、宽度和透明度调整。
  • 可选地面飞溅粒子，并控制飞溅数量与速度。
  • 可在当前所选模型中心创建雨区，也可在世界原点创建。
  • 支持自定义模拟开始帧和结束帧。
  • 支持重复生成并更新、选择控制器和一键删除整套雨效。

参数说明

  • 降雨预设：快速载入不同强度、速度、风力和飞溅参数。
  • 宽度 / 深度：控制雨滴发射区域覆盖范围。
  • 雨云高度：控制雨滴发射器所在高度。
  • 地面高度：决定飞溅区域和地面显示位置。
  • 雨量：每秒发射的雨滴数量，数值越大场景计算量越高。
  • 风向 X / Z：控制雨滴的水平偏移方向和强度。
  • 扰动：增加雨滴运动的随机变化，避免轨迹过于整齐。
  • 雨滴长度 / 宽度：控制 Viewport 2.0 中雨丝的外观。
  • 启用飞溅：在地面区域创建额外的飞溅粒子。

工具使用教程

  1. 如果希望雨区围绕角色或场景模型生成，先在 Maya 中选择目标模型或模型组。
  2. 打开 Bingo_下雨特效。
  3. 选择小雨、中雨、暴雨或斜风暴雨预设。
  4. 设置降雨区域宽度、深度、雨云高度和地面高度。
  5. 根据镜头需要调整雨量、下落速度、风向、扰动和雨滴外观。
  6. 需要地面水花时勾选 启用飞溅，再设置飞溅数量和速度。
  7. 设置模拟的开始帧和结束帧。
  8. 需要以所选物体为中心时保留 以当前选择中心创建；否则取消勾选。
  9. 点击 生成 / 更新下雨特效。
  10. 播放时间轴检查雨滴方向、覆盖范围和飞溅位置。
  11. 修改参数后再次点击生成按钮即可更新整套效果。
  12. 点击 选择控制器 可整体移动雨区；不再使用时点击 删除雨效。

使用建议与注意事项

  • 先用中低雨量调整范围和风向，确认构图后再提高雨量，可明显减少调试等待时间。
  • 雨滴需要播放若干帧后才会布满区域，从开始帧立即观察时数量较少属于正常情况。
  • 地面飞溅属于独立粒子系统，关闭飞溅可降低场景计算量。
  • 最终渲染前应根据所用渲染器检查粒子材质、运动模糊和透明度效果。
  • 超大降雨范围与高雨量组合会增加播放和缓存开销，请按镜头实际可见范围设置。
