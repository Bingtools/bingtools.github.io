TOOLBOX FUNCTIONS / WORKFLOW

安装完成后，打造自己的 Maya 工具工作台

10 项核心能力 · 7 步快速开始

01 / FUNCTIONS

工具箱核心能力

  • 01搜索、筛选与收藏

    支持中文和拼音搜索、分类筛选、收藏及置顶常用工具。

  • 02工具卡片个性化

    右键设置图标、颜色、快捷键和所属分类。

  • 03中文功能介绍

    点击工具右侧的 i，查看功能和选择要求。

  • 04拖入底部快捷栏

    把高频工具拖到时间轴附近，减少重复查找。

  • 05快捷栏自由编排

    图标可左右排序、自适应缩放，并能设置背景色。

  • 06快捷栏自定义按键

    右键快捷栏图标，为常用操作设置快捷键。

  • 07创建 Python / MEL 工具

    把自己的脚本制作成可直接运行的工具按钮。

  • 08添加外部入口

    可添加网页、软件、文件夹或系统命令按钮。

  • 09浮动与停靠模式

    在独立浮动窗口和 Maya 停靠模式之间切换。

  • 10工具卡片上下排序

    在真实分类中拖动工具卡片调整顺序，个人配置会自动保存。

02 / QUICK START

7 步开始使用

  1. 打开工具箱

    启动 Maya 后，点击状态栏里的老虎图标。

  2. 查找工具

    从左侧选择分类，或直接搜索名称。

  3. 准备对象

    先选择控制器、骨骼、模型或关键帧。

  4. 单击运行

    单击工具卡片，执行对应功能。

  5. 查看说明

    选择要求不清楚时，点击右侧的 i。

  6. 加入快捷栏

    把常用工具拖到时间轴附近的快捷栏。

  7. 设置快捷键

    右键工具或快捷栏图标，自定义快捷键。

QUICK START / 04 STEPS

从安装到运行

01

关闭 Maya

保存当前场景并退出 Maya，避免安装时旧模块仍被占用。

02

运行安装包

双击 Bingo ToolBox EXE，按提示完成安装；无需手动指定 scripts 路径。

03

重新打开 Maya

启动 Maya 后等待模块加载，在顶部菜单栏找到 Bingo 入口。

04

选择并运行工具

进入 Bingo → ToolBox，按分类浏览工具；正式处理前建议保存场景副本。

Maya 菜单栏 → Bingo → ToolBox → 选择分类 → 打开工具
